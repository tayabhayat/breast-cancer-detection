
# 🎗️ Breast Cancer Detection — Machine Learning

## 📌 Project Overview

This project applies supervised machine learning to breast cancer classification using a Decision Tree model.

### 🎯 Objectives
- Understand the machine learning workflow.
- Prepare and process a dataset.
- Train a Decision Tree classification model.
- Evaluate model predictions.
